From Aaron

#+begin_src emacs-lisp :tangle no

(defun c/insert-comment-attribution ()
  "Insert a comment attribution.

e.g. - Aaron, Fri Jan 07 2022"
  (interactive)
  (insert "- Aaron")
  (save-excursion
    (insert ", ")
    (c/insert-log-date)))

(define-key global-map (kbd "C-c !") #'c/insert-log-date)
(define-key global-map (kbd "C-c C--") #'c/insert-comment-attribution)

#+end_src

* Timing
Aaron provided his code.

In early init:

#+begin_src emacs-lisp :tangle no
(defvar c/early-init-el-start-time (current-time) "Time when early-init.el was started")
(defvar c/section-split-time c/early-init-el-start-time)

(defun c/get-section-split-time ()
  "Return the time since the init or since the last time this was called."
  (let ((now (current-time)))
    (prog1
        (float-time (time-subtract now c/section-split-time))
      (setq c/section-split-time now))))

(defvar c/previous-section nil)

(defun c/start-section (file heading)
  "Print the split time for the previous heading."
  (when (and c/previous-section
             (not noninteractive))
    (let ((inhibit-message t)
          (time (* 1000 (c/get-section-split-time))))
      (when (> time 3)
        (message "%6s • %4dms • %s" (car c/previous-section) time (cdr c/previous-section)))))
  (setq c/previous-section (and file heading (cons file heading))))
#+end_src

* Miles and GC

This weekend I had success lowering my startup time increasing the garbage collection time, then resetting it after startup has finished.

#+begin_src emacs-lisp :tangle no
(defvar c/gc-cons-threshold (* 16 1024 1024)
  "The value of `gc-cons-threshold' after Emacs startup.")

(setq gc-cons-threshold most-positive-fixnum)

(add-hook 'emacs-startup-hook
          (lambda ()
            (setq gc-cons-threshold c/gc-cons-threshold)))
#+end_src

I also added most of the early-init.el additions from minmal-emacs.d. This also helped decrease the init time to some degree, but not as significant as the above garbage collection.
